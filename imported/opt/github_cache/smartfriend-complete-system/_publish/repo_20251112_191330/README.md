# smartfriend-complete-system (code drop)

هذا إسقاط أولي لمجلدات الأكواد مفكوكة من خادم الإنتاج.
التقسيم:
- `smartfriend-suite/` خدمات وواجهات ذكية.
- `ffactory/` حزمة التحليل الجنائي والأدوات.
- `smartfrind/` النواة والبوابة.
- `Psmart/`, `opt-projects/`, `SmartFrind_Miracle/`, `ULTIMATE_FUSION/` مشاريع فرعية.

> المفاتيح والتوكنات يجب أن تكون من خلال متغيرات بيئة أو ملفات `.env` غير مُلتزمة.
